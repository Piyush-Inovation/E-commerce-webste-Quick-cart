================================================================================
                        INSTALLATION INSTRUCTIONS
================================================================================

INITIAL SETUP
-------------
1. Clone the repository
2. Navigate to project directory
3. Run installation command

INSTALLATION COMMANDS
---------------------
# Using npm (Recommended)
npm install

# Using npm with clean install (uses package-lock.json)
npm ci

# Using yarn
yarn install

# Using pnpm
pnpm install

================================================================================
                        RUNNING THE APPLICATION
================================================================================

DEVELOPMENT MODE
----------------
npm run dev                         # Starts development server on localhost:3000
                                    # Includes hot-reloading and Turbopack

PRODUCTION BUILD
----------------
npm run build                       # Creates optimized production build
npm start                           # Starts production server

CODE QUALITY
------------
npm run lint                        # Runs ESLint to check code quality

================================================================================
                        ENVIRONMENT VARIABLES REQUIRED
================================================================================

PUBLIC VARIABLES (Client-Side Access)
--------------------------------------
NEXT_PUBLIC_CURRENCY                # Currency symbol ($, ₹, €, etc.)
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY   # Clerk publishable API key

PRIVATE VARIABLES (Server-Side Only)
-------------------------------------
CLERK_SECRET_KEY                    # Clerk secret API key
MONGODB_URI                         # MongoDB Atlas connection string
INNGEST_SIGNING_KEY                 # Inngest signing key for security
INNGEST_EVENT_KEY                   # Inngest event API key

OPTIONAL VARIABLES (Image Upload)
----------------------------------
CLOUDINARY_CLOUD_NAME               # Cloudinary account cloud name
CLOUDINARY_API_KEY                  # Cloudinary API key
CLOUDINARY_API_SECRET               # Cloudinary API secret

================================================================================
                        TROUBLESHOOTING
================================================================================

COMMON ISSUES
-------------
Issue: "Cannot find module 'next'"
Solution: Run 'npm install' to install all dependencies

Issue: "Port 3000 already in use"
Solution: Run 'npm run dev -- -p 3001' to use different port

Issue: "MongoDB connection failed"
Solution: Verify MONGODB_URI in .env file and whitelist IP in MongoDB Atlas

Issue: "Clerk authentication error"
Solution: Check CLERK_SECRET_KEY and NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY
